# PM2.5 prediction web app -- runtime dependencies.
#
# Lower bounds are the versions this app is developed and tested against;
# the deployed model artifacts were produced with xgboost 3.4 / lightgbm 4.7 /
# catboost 1.2 and are loaded by unpickling, so those three in particular
# should not be downgraded.
#
#   pip install -r requirements.txt
#
# Upper bounds are deliberate. deploy/deploy.sh reinstalls this file on every
# deploy, so an unpinned major release could break a running site without a
# single line of this repository changing. Verified working as high as
# pandas 3.1, numpy 2.5, scikit-learn 1.9, shap 0.54, xgboost 3.4 (the
# deployment server resolves to those). Raise a bound deliberately, after
# running the test suite against the new version.
